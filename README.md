# ONYT site (Next.js + TypeScript)

```bash
npm install
npm run dev
```

Open http://localhost:3000

- `components/` one component per section (Nav, Hero, Services, Work, Process, Capabilities, Cta, Footer...)
- `app/globals.css` all styles, theme tokens (dark/light)
- `lib/motion.ts` scroll, cursor, theme toggle, counters, hero canvas
- `public/` your logo and brand images
